# Подключение AI к KITON через MCP

MCP позволяет ChatGPT, Codex, Claude и другим совместимым приложениям работать с данными вашего личного кабинета. Каждое подключение действует от имени вошедшего пользователя: репетитор видит только свой кабинет, ученик - только свои данные, родитель - только привязанных детей.

!!! info "До включения в production"
    Функция подготовлена локально и ещё не развёрнута. URL ниже начнёт работать после отдельного согласованного обновления сервера.

## URL подключения

```text
https://api.kiton.pw/mcp/cabinet
```

1. Откройте добавление удалённого MCP-сервера в AI-приложении.
2. Вставьте URL.
3. Браузер откроет страницу входа KITON. Войдите в обычный кабинет.
4. Проверьте название приложения и список разрешений.
5. Разрешения на загрузку и изменение файлов выключены по умолчанию. Включайте их только при необходимости.
6. Нажмите «Разрешить подключение» и вернитесь в AI-приложение.

Пароль KITON не передаётся AI-приложению. Клиент получает короткоживущий токен только с подтверждёнными правами.

## Какие данные доступны

- основные данные кабинета;
- ученики, расписание, домашние задания и оплаты в рамках роли пользователя;
- папки и файлы, к которым у пользователя уже есть доступ в KITON;
- чтение PDF, DOCX, XLSX, PPTX, TXT, CSV и изображений;
- OCR сканов, рендер страниц и скриншоты фрагментов.

Ученик и родитель не получают доступ ко всей библиотеке репетитора. Им доступны только файлы, выданные через доступные занятия и домашние задания.

## Управление подключениями

Откройте «Настройки» и блок «AI и MCP». Там можно:

- увидеть активные приложения и дату последнего использования;
- проверить предоставленные разрешения;
- отдельно включить загрузку и управление файлами;
- отключить одно приложение;
- нажать «Отключить все AI-приложения»;
- посмотреть последние вызовы без содержимого документов.

После изменения разрешений действующий access token отзывается. AI-приложению может потребоваться повторное подключение.

## Ограничения безопасности

Через пользовательский MCP нельзя изменять оплаты, публиковать данные, отправлять материалы ученикам или родителям и удалять файлы. Архивирование требует явного подтверждения и не удаляет физический файл. Реальные системные пути сервера никогда не возвращаются клиенту.

Если вы не узнаёте приложение в списке подключений, сразу отключите его. При сомнении используйте «Отключить все AI-приложения» и смените пароль KITON.
