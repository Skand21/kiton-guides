# Создание и завершение занятия

Точка входа: [Расписание](https://kiton.pw/tutor/schedule).

1. Нажмите «Добавить занятие», выберите ученика и предмет.
2. Для первого урока оставьте разовый тип, укажите дату, время и длительность.
3. Сохраните. При желании настройте повторение отдельным действием после сохранения.
4. После урока откройте занятие в календаре и сохраните фактический результат.

Результат: статус «Проведено» завершает быстрый старт. Можно создать следующий урок, задать ДЗ
или подготовить результат для подключённого родителя. Отмена и пропуск не считаются проведением.

Если есть пересечение, прочитайте предупреждение и проверьте время в календаре.
При ошибке сохранения исправьте поля и повторите. Если занятие уже видно, не создавайте дубликат.
Будущий урок можно открыть сразу, но результат следует отмечать по факту проведения.
